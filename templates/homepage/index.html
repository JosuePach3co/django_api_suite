Flujo de Datos

Intermediario Seguro

La aplicación funciona como un puente seguro. El cliente nunca toca la base de datos directamente, garantizando seguridad y validación en cada petición:

  • 1. El cliente envía una petición HTTP (GET, POST).
  • 2. Django REST Framework procesa y valida la data.
  • 3. Firebase Admin lee o escribe en Realtime Database y retorna el JSON al cliente.

Estructura de Endpoints

GET

/landing/api/index/

Obtiene todos los registros almacenados en la colección landing_entries de Firebase. Devuelve un objeto JSON con los nodos.

POST

/landing/api/index/

Recibe un payload JSON. El servidor adjunta un timestamp automático y lo guarda mediante ref.push() en Firebase.

PUT

/demo/rest/api/index/<id>/

Demo local para reemplazar completamente un registro, identificado por su UUID.

DEL

/demo/rest/api/index/<id>/

Elimina lógicamente un registro (marca is_active como false), preservando el historial.
